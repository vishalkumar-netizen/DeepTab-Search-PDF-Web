# DeepTab-Search-PDF-Web now called AeroSearch
DeepTab Search (now Aerosearch) is a powerful productivity tool built for researchers, students, and professionals who manage dozens of open tabs.
Instead of manually switching between tabs and using Ctrl+F repeatedly, DeepTab Search automates the entire process. It scans both web pages and PDF documents efficiently, helping you find exactly what you need in seconds.

✨ Key Features

Universal Search: Works across standard web pages and PDF files
Efficient PDF Handling: Extracts text smoothly without slowing down your browser
Bulk Cleanup Mode: Option to automatically close tabs that don’t contain your keyword
Sidebar Integration: Runs inside the Firefox Sidebar for a distraction-free workflow
100% Private: Fully offline — no data collection or external servers involved

🛠️ How to Use

    Open the extension from the toolbar/extension bar
    Enter the word or phrase you want to search
    (Optional) Enable Close tabs with no match to auto-clean your tabs
    Click Start Search to begin scanning
    When a match is found, the tab opens and the search pauses
    Click Resume to continue or Stop to end anytime


Save time, stay focused, and take full control of your tabs with DeepTab Search.
